# 拷贝漫画 CopyReader

一个供个人使用的 Android 第三方漫画阅读客户端，版本 1.8.0。显示名称为“拷贝漫画”，独立安装，不覆盖原版客户端。使用相同私有签名的个人安装包可覆盖更新；自行编译的签名由构建者管理。

## 1.8.0 弧形书架与交互

- 用圆弧轨道增加书架纵深，按屏幕高度调整书册尺寸；加强纸页、书脊、接触阴影与深色纸面的层次。修复纸面渐变引用，分页控件避开悬浮导航。
- 本地收藏、自选与阅读记录保留作品状态。书架优先显示“已完结”；旧收藏缺少状态时，在选书停稳后补读该作品详情，并缓存结果。状态未知时只显示历史更新时间，不据日期推断连载或完结。
- 设置提供淡入淡出、轻盈滑动和关闭动画，以及快速、标准、舒缓三档速度；带可点击预览。增加封面淡入和轻量按压反馈，动画闲置时不运行循环。
- 从右上角主题按钮圆形展开白天／暗夜主题，保留当前书架与已解码的封面。支持连续切换；系统减少动态效果、关闭动画或旧 WebView 不支持时直接切换。
- 增加 Android 原生书架轻触反馈，按书脊切换触发并限频，遵循系统触感设置。可独立关闭，不新增权限。
- 设置按阅读与外观、动画与触感、数据与备份、连接与高级设置折叠分组；记住收起状态，底部提供“关于该应用”。偏好和作品状态均进入本地备份。
- 沿用原包名、私有签名和图标，可覆盖安装个人旧版；保留30本自选、惯性、账号、评论、阅读记录与章节定位。

## 1.7.0 投影、自选与30本书架

- 补上逐册遮挡阴影、底面投影、接触阴影与纸面明暗。抬起的书投射更长、更淡的阴影；方向和位置随书架姿态连续变化。遮挡阴影按尺寸和主题缓存，底面由独立画布绘制；Android资源拦截器支持经尺寸、体积和PNG头校验的本地阴影图片。
- 立体书架与预览最多陈列30本不同漫画，账号收藏请求每批30本。网格可继续浏览所有已载入的收藏，收藏总数不受展示上限影响。
- 增加独立“自选”书架：从本地、已载入账号收藏或在线搜索中挑选最多30本。选择与排列都保存在本地，不修改账号收藏。
- 点右上角铅笔打开编辑器；添加、移除、拖动、上下移和清空先进入草稿，点“完成”后保存。支持拖到边缘自动滚动、取消恢复、键盘上下排序及搜索请求竞态保护。
- 自选顺序与来源偏好可在重启后恢复；本地备份包含自选。旧备份未带自选时保留现有自选，带自选时恢复其顺序；导入去重并限制为30本。
- 候选列表每次显示30本，远处封面按需加载。写入被拒绝时保留草稿和原存储状态；未保存退出可选择保留编辑或放弃。
- 原有惯性、账号协议、评论、阅读记录和章节定位继续保留。沿用原包名、签名和圆润图标。

## 1.6.0 书架细节与统一界面

- 根据用户提供的实际对照图调整内容边界、书册宽高、封面占比、短书脊、纸页边线和相邻书册的连续起伏。书架限宽520px，移动端与平板使用同一比例规则。
- 书脊最多显示8个字形，其余用省略号收束，完整名称保留在下方书名与无障碍标签中。封面图增大，底部更新日期缩短。
- 页头在纵向浏览时保留；账号入口并入来源切换行，点入口查看账号菜单。数量、视图切换和刷新独立成一行；账号总量与已载入数量分别显示。
- 立体书架下方提供最多12本的收藏预览，点“查看全部”切换完整网格。远处的预览封面进入视口附近才加载；打开预览作品后返回，会定位到同一本书。
- 作者缺失时使用已有阅读记录或真实更新时间补充信息。统一暖白背景、中性深灰纸面、字号、边距、分隔线、图标笔画和较轻的悬浮底栏。
- 首页、详情、设置、历史、评论和弹窗沿用统一的界面规则。系统栏与浅色页面底色同步；保留圆润图标、原有惯性、阅读目录跳转和章节定位。
- 运动实现、账号/评论协议、加密凭证格式及备份版本保持原样。使用同一包名与签名，可覆盖安装。

## 1.5.2 惯性书架与交互优化

- 书架根据松手速度惯性减速，再平稳吸附到书脊；慢拖精确选书，快滑可浏览多本。按住立即停止，下一次主动点击可打开当前漫画。
- 连续反向拖动、按钮及键盘切换可打断正在进行的动画；横向选书和页面纵向滚动分别判断，不误开封面。取消触摸、离开页面和退到后台会收束动画。
- 使用单个按需运行的动画时钟和固定数量的书册节点，只在边缘循环复用；没有每帧重建书架或空闲动画。封面只预载当前位置附近的书籍。
- 主标签恢复各自的浏览位置；首页加载更多保留既有封面；逐页翻页保留工具栏、滑杆和手势区域。章节末尾的“返回目录”也进入当前漫画详情。
- 稳定书名与分页区域的高度，调整触控面积、阅读滑杆、轻量底栏和弹窗过渡；深色主题使用暗纸面。系统开启减少动态效果时，保留跟手操作，关闭松手惯性及过渡。
- 保留1.5.1的目录定位、高亮章节、账号、评论与圆润图标；更新不需要清除数据。

## 1.5.1 纸质书架与阅读跳转

- 按用户提供的截图重做白色纸质书册、竖排书脊、内嵌封面和抬高抽出的选中书籍；替换1.5.0的大封面轮播。
- 书架连续跟手并吸附，固定左右遮挡顺序；点旁边书脊先选中，点选中封面或书名进入详情。每次最多绘制31个循环副本，实际收藏不会重复。
- 标题恢复系统无衬线字体，调整细网格、历史/搜索入口和悬浮底栏比例。移除宋体资源，圆润图标沿用1.5.0。
- 阅读中点“目录”会进入当前漫画详情和目录，包含从历史直接进入阅读的情况，不再退回应用首页。
- 首页“继续阅读”先进入对应漫画详情，自动切到保存的章节分组，加载并定位、高亮“上次读到”的章节。详情页的继续阅读仍保留章节和页码。
- 支持首批目录之外的章节定位、加载失败重试和取消定位；章节或分组移除时显示状态，不错误标记其他章节。
- 构建前清理旧的资源归档和中间APK，防止已删除资源残留。

## 1.4.0 评论发送

- 在作品或章节评论页底部点“发表评论”，使用已登录的拷贝账号发送顶层评论。
- 未登录时先登录，再回到原评论编辑界面；重新登录不会自动提交草稿。
- 编辑器支持1000个Unicode字符、字数提示、空内容校验；作品和章节的草稿分别保存在当前页面内存中。
- 发送中禁用重复提交并保留编辑窗口；成功后刷新当前评论，失败保留输入内容。
- 无法确认网络请求结果时提示先刷新核对，不自动重发。
- 写入通过原生层绑定的登录域名和协议认证，令牌不返回页面，也不进入本地备份。

当前支持作品评论和章节评论发送，暂未提供针对某条评论的回复、点赞或展开子回复。已通过本地模拟发送验证；没有使用真实账号实际发表评论。

## 1.3.0 评论浏览

- 在作品详情中打开“作品评论”，阅读器顶部和章节末尾打开“本话评论”。
- 读取拷贝现有的作品评论及章节评论；在阅读器打开时可以切换两种讨论。
- 显示读者昵称、头像、时间、评论正文，以及接口直接返回的回复对象；支持分页、刷新、失败重试和空状态。
- 查看评论不需要登录，不发送账号凭证；评论正文以纯文本显示，不执行远程HTML或脚本。
- 返回阅读器时恢复原章节和页码；切换评论对象或退出页面后，旧请求不能覆盖新页面。

评论读取使用“设置 → 账号登录线路”当前配置的接口与协议；发送使用当前登录会话绑定的域名和协议。新版默认接口已验证可匿名读取；旧版漫画接口没有这些评论路由。评论正文和编辑草稿不保存到磁盘或备份。

## 技术实现

界面使用随APK打包的HTML、CSS和原生JavaScript，由Android WebView显示。JavaScript通过`ReaderNative`桥接调用Java原生层，由后者处理HTTPS/JSON接口、账号请求、图片磁盘缓存和系统功能。漫画与账号数据直接请求既有服务，本工程没有单独部署的后端服务。

本地书架、阅读历史和设置通过Android SharedPreferences保存；账号凭证通过Android Keystore与AES-GCM加密。文件备份使用系统文档选择器，原生层还处理音量键翻页、屏幕常亮及系统栏。项目采用混合应用架构，没有第三方运行时框架。

## 已实现

- 在线搜索漫画，浏览最近更新、热门作品和常见题材。
- 漫画详情、简介、作者、分组章节目录、章节筛选及分页加载。
- 本地书架、最近阅读记录、按页保存进度、继续阅读。
- 作品评论与章节评论的匿名浏览、分页、刷新、错误重试和登录后发送。
- 用户名和密码登录拷贝漫画账号，读取分页账号书架，主动加入、移除账号收藏。
- 本地与账号书架分别管理；退出、切换账号或凭证过期时清理内存中的账号书架。
- 登录凭证在 Android 原生层通过 Android Keystore 与 AES-GCM 加密保存；密码不持久保存。
- 竖向滚动和逐页阅读，滑动或点击两侧翻页，音量键翻页，双指缩放。
- 深色、浅色、跟随系统主题；阅读时保持屏幕常亮。
- 章节图片懒加载、失败重试、近期图片缓存，图片缓存目标上限约 120 MiB。
- 书架、历史和偏好的 JSON 备份导入、导出。
- 数据源备用接口发现、手动 HTTPS 接口设置及连接测试。

界面和脚本全部随应用打包。应用直接取得漫画元数据与图片，不运行源站网页脚本，不集成广告或统计 SDK，不打开弹窗或外部广告链接。漫画图片中原本嵌入的推广内容不会自动识别删除。

## 使用范围

需要 Android 8.0 或更新系统，以及系统提供的 Android System WebView。仅申请 INTERNET 权限，文件备份通过系统文档选择器读写。

这是第三方独立客户端，不是对官方 APK 的修改，与拷贝漫画官方无关联。1.1.0 新增账号登录和账号收藏管理。本地备份不包括账号、令牌、密码或云端书架；按页阅读进度仍只保存在本机。暂不提供账号注册、短信登录、密码找回、云端阅读进度同步、整部漫画离线下载、推送追更或应用内自动升级。

1.1.1 将账号接口与漫画接口分别设置。新版账号默认使用 `https://api.copy202601.com`，按维护中的客户端参考使用 COPY/3.0.0、version 2025.08.15、platform 1 的请求配置；登录表单仅含 username、password、salt。旧版协议仅在显式选择时使用。账号错误保留源站提示，并提示核对注册用户名与线路。

登录请求只发送到用户在登录页看到的 HTTPS 账号接口，不会自动把密码依次尝试到多个域名。凭证绑定登录时的域名与协议；账号请求不跟随重定向，不写入公共 API 缓存。更换账号线路后，退出并重新登录才会更换已保存的会话。账号端缺少旧章节路由并返回 404 时，回到不带凭证的原漫画读取接口。

数据源的接口、网络线路、章节和图片链接可能变化。本版本保留源站访问限制；不支持的或被限制的章节会显示错误。网络请求会直接发往数据源及其图片服务器，这些服务器能够看到通常的网络请求信息。

## Android Studio 构建

1. 克隆或下载源码。先按下方命令行构建生成本机开发签名，再使用 Android Studio 打开此目录。
2. 安装 Android SDK Platform 35、Build Tools 35.0.0，使用 JDK 17。
3. 等待 Gradle 同步，生成 app 的 APK。

Gradle 配置使用 Android Gradle Plugin 8.9.1，没有第三方运行时依赖。IDE/Gradle 路径未在本环境实际执行；下面的手工工具链已完整执行并生成安装包。

公开仓库不包含个人开发签名、账号凭证或用户书架数据。`build.sh` 会在 `signing/` 中生成你自己的开发密钥；它已被 `.gitignore` 排除。请自行备份该密钥，同一签名和包名的后续版本才能覆盖更新。自行生成的签名与已发布个人安装包不同，不能覆盖安装后者。

输出为 `dist/CopyReader-1.8.0.apk`。流程为 Java 编译、aapt2 资源打包、D8、zipalign、apksigner。若没有 javac，脚本会从 Maven Central 下载 Eclipse ECJ 3.38.0 编译器作为开发工具。ECJ 不包含在源码压缩包中。

## 界面测试

测试只使用脚本中的合成作品与合成图片，不会请求真实漫画接口。安装 `playwright-core` 后，指定本地 Chromium / Chrome 的可执行文件：

```bash
CHROME_PATH=/你的/chrome路径 node tests/ui-smoke.cjs
```

运动计算可直接运行 `node tests/shelf-motion.cjs`，投影检查运行 `node tests/shelf-materials.cjs`，不需要浏览器。只检查书架交互可为界面命令增加 `SHELF_ONLY=1`。测试输出记录至 `checks/`。在 ChatGPT 的预置运行环境中，可使用 `CODEX_PRIMARY_RUNTIME_NODE_MODULES` 指向预装依赖目录。

Java 协议测试只需 JDK 和 JSON-java 20240303。将该工具依赖放到 `tools/json.jar` 后，编译 `AccountProtocol.java` 与 `tests/AccountProtocolTest.java`，运行 `app.copyreader.clean.AccountProtocolTest`。该测试使用内存 HTTP 连接，校验编码、认证请求头、重定向拒绝和错误处理，不使用真实账号。

评论协议检查需同时编译`CommentProtocol.java`与`tests/CommentProtocolTest.java`，运行`app.copyreader.clean.CommentProtocolTest`。目前135项界面检查、110组确定性运动检查、21组投影几何检查、12项账号协议检查与12项评论协议和13项本地PNG加载检查均通过。
